---
title: Instagram
description: Publish Instagram professional-account media with explicit container processing, comments, and metrics handling.
icon: instagram
---

The direct Instagram adapter uses Instagram Login for a professional account. Supply an access token and the account ID on the server; the adapter does not perform OAuth, account discovery, or tenant membership checks.

```ts
import { createSocial, connectedAccountRef } from "@opencoredev/social-sdk";
import { instagram } from "@opencoredev/social-sdk/instagram";

const social = createSocial({
  backend: instagram({
    auth: {
      accessToken: process.env.INSTAGRAM_ACCESS_TOKEN!,
      accountId: process.env.INSTAGRAM_ACCOUNT_ID!,
    },
  }),
});
const account = connectedAccountRef({
  backend: "default",
  platform: "instagram",
  accountId: process.env.INSTAGRAM_ACCOUNT_ID!,
});
const prepared = social.posts.prepare({
  targets: [{ account }],
  content: {
    text: "A professional-account update",
    media: [
      {
        kind: "image",
        source: { kind: "https-url", url: "https://cdn.example.invalid/image.jpg" },
      },
    ],
  },
});
```

Images, videos, and carousels use public HTTPS media. The adapter stores a workflow for child containers, parent creation, and continuation after asynchronous processing; retain the processing outcome and reconcile explicitly. It does not silently crop, change account visibility, or convert unsupported media.

The adapter declares post reads, status, analytics, comment reads, and comment replies. Metrics are the values returned by Instagram Insights; absent metrics remain absent. Replies require a comment reference returned by a comment read. Account authorization and Instagram professional-account eligibility remain application responsibilities. See the [capability matrix](/docs/reference/capabilities) and [events](/docs/events).
